# Long Arc Songs

Official website source for **Long Arc Songs**, the UK songwriting partnership of Phil and Jay.

The site presents featured songs first, followed by genre-led catalogue browsing across:

- Contemporary pop
- Country and Americana
- Soul and R&B
- Pop-folk and acoustic
- Big band and jazz-pop
- Adult contemporary

## Development

Requires Node.js 22.13 or later.

```bash
npm ci
npm run dev
```

Create a production build with:

```bash
npm run build
```

The current catalogue entries are intentional placeholders ready to be replaced with final song titles, audio and metadata.
